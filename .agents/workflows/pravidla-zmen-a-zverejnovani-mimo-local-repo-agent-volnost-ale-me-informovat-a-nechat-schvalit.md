# BEZPEČNOSTNÍ PROTOKOL A PRAVIDLA PRO REPOZITÁŘ

1. V rámci lokálního repozitáře máš plnou autonomii pro čtení a zápis kódů.
2. Před JAKÝMKOLIV spuštěním shell příkazu (terminál), jakoukoliv změnou mimo lokální repozitář, nebo před zavoláním jakéhokoliv externího MCP nástroje MUSÍŠ uživateli zaslat strukturovanou zprávu a počkat na schválení.

Zpráva před akcí musí mít tento formát:
- **Co chci udělat:** [Přesný popis akce/příkazu]
- **Důvod:** [Proč je tato akce nutná pro splnění úkolu]
- **Možná rizika:** [Co se může pokazit, dopad na systém/externí služby]

Bez explicitního schválení uživatelem nesmíš žádný shell příkaz ani externí MCP spustit.
